# Contributing to IndianMiningGPT

Thank you for your interest in contributing to IndianMiningGPT.

IndianMiningGPT is an open-source initiative focused on developing domain-specific Small Language Models (SLMs) for the Indian mining and natural resources sector.

We welcome contributions from:

* Mining professionals
* Researchers
* Students
* Educators
* Data scientists
* Machine learning engineers
* Open-source contributors

---

# Project Philosophy

IndianMiningGPT follows five guiding principles:

1. Domain specialization over generality.
2. Reproducibility over rapid experimentation.
3. Simplicity over unnecessary complexity.
4. Open collaboration.
5. Practical industry value.

---

# Development Workflow

## Branch Strategy

Main branches:

```text
main
develop
```

### main

Stable production-ready code.

### develop

Active development branch.

---

# Commit Convention

Use conventional commits:

```text
feat:
fix:
docs:
refactor:
test:
chore:
```

Examples:

```text
feat: implement rope attention
fix: correct tokenizer padding logic
docs: update roadmap phase 2
test: add tokenizer validation tests
```

---

# Code Style

## Python

Follow:

* PEP8
* Type hints where practical
* Clear variable names
* Modular design

Avoid:

* Excessively long functions
* Hard-coded paths
* Unused imports

---

# Pull Requests

Before submitting:

* Ensure code runs successfully
* Update documentation if required
* Provide a clear description
* Reference related issues

---

# Reporting Issues

When reporting issues include:

* Operating system
* Python version
* JAX version
* GPU details
* Error message
* Reproduction steps

---

# Community Standards

Please maintain a professional and respectful environment.

Constructive discussion and technical debate are encouraged.

Personal attacks, harassment, and disrespectful behavior will not be tolerated.
